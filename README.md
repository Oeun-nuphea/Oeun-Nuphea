## 🚀 What I'm Working On

### **ltng-chat-api**
Real-time chat backend at scale. NestJS + WebSocket (Socket.IO), Redis for horizontal scaling, MongoDB + MySQL dual-database support, role-based access control.

- ✅ Event-driven architecture with RabbitMQ
- ✅ Distributed WebSocket with Redis adapter
- ✅ RBAC & audit logging
- ✅ Caching strategies for sub-100ms latency
- ✅ Containerized deployment (Docker Compose + nginx)
